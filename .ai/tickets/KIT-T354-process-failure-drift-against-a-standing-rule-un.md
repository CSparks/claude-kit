## Description
Process failure (drift against a standing rule, unflagged): universal editor tool code (stage lighting rigs, outline stage pass, shader preview, ground chunk view, animate/driver hooks — 19 files / 2820 lines) accumulated in stiletto's crates/editor across many landings although the standing rule (ST-D057 rapid-game FIRST, ST-D112/D117) was clear from day one; Claude even mis-described Chris's reminder as a new 'superseding' directive. ROOT CAUSE: no gate distinguishes game REGISTRATION (data) from TOOL CODE in a consumer's editor crate, and the pre-write gate does not consult the framework contract's placement rule. FIX: a placement gate for consumer repos — a write under <game>/crates/editor (or any path the framework contract marks tool-space) that adds a Bevy system/plugin/material/render pass blocks with 'belongs in rapid-game' unless the file is a registry (data-only), plus orient's contract block naming the placement rule explicitly.
