## Description
A landing report asserted the state of code it did not touch, and the claim drove a whole later slice. T127min comment #6 closed with 'Preview is still the legacy three.js one (ST-D015, untouched)' — the agent had not looked: the assets preview has rendered on rg-render WebGPU since HOD-T153 (rapid-game 7ff5fd1). That single ungrounded line became the premise of the T127s1 brief (embed the harness, delete the three.js path), and both halves were unbuildable. ROOT CAUSE: the evidence floor covers what a landing DID (test artifact required) but not what a landing SAYS ABOUT ADJACENT CODE. A 'still X / untouched' claim about code outside the diff is an assertion with no receipt and no gate. Proposed: the commit/landing gate treats a state claim about code outside the change as needing a pointer (file:line, sha, or query) the same way a fix needs a test — or the report says 'not checked'.
