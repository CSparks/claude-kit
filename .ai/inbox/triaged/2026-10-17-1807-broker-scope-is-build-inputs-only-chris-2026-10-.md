(decision) "Broker scope is build inputs only (Chris 2026-10-17, verbatim: 'This is exclusively for anything that can break a bill because of file changed. This is not include documentation or scripts in that same repo that have nothing to do with a binary build.' [bill = build]). The broker owns ONLY files a binary build reads (.rs, Cargo.toml, Cargo.lock, build.rs, include_str!/include_bytes! targets, .cargo/config). Docs, .ai/, and scripts that no build reads are written directly in the same checkout: never queued, never pause the daemon, never blocked by the dispatch guard. Enforced by KIT-T553 tests."
